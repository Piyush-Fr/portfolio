# Project Requirements

## Tech Stack
For this project, we will use a modern React stack to allow for component-based architecture while maintaining precise design control:
- **Core Framework**: Next.js (App Router) with React 18+ and TypeScript
- **Styling**: Tailwind CSS v4 (for rapid layout and consistent design system enforcement).
- **Build Tool**: Next.js built-in bundler (Turbopack/Webpack).

## Requirements
- **Layout**: A rigid, responsive grid-based layout inspired by Swiss design principles.
- **Theme**: Dark mode aesthetic (Black background with Red accents and white text).
- **Performance**: Minimal external dependencies; fast loading times.
- **Interactivity**: 
  - Dynamic hover states on project lists (revealing tags/context).
  - Floating action button that opens a high-contrast, full-screen overlay menu.
- **Typography**: Integration of a modern, clean sans-serif font (like Inter) with monospaced accents.
